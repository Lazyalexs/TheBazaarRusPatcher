# Проверка сборки v0.7.3

Дата: 2026-10-08. Цели: Steam и Tempo Launcher, Windows x64.

- dotnet publish Release, win-x64, self-contained, single-file завершён успешно.
- Версия сборки и обоих EXE: 0.7.3.0.
- Встроенные translation-patch.json и gamedata-tooltips.json побайтно совпадают с исходными ресурсами по SHA-256.
- 17299 переводов, 139 записей словаря. Относительно v0.7.2 добавлена 351 запись (306 игровых данных и 45 UI), исправлены 23 прежних перевода; в словаре добавлены 2 и исправлены 7 записей.
- Сохранённые ручные решения, JSON без дубликатов, переменные и rich-text-теги изменённых строк проверены. Ready → «Играть» и Defeat → «Поражение» включены в ресурс.
- --verify-patch успешно выполнен для обоих именованных EXE; оба выводят 17299 записей.
- --check успешно выполнен для Steam и Tempo. Режим без установки проверил общий кэш, Steam и найденный каталог Tempo; ошибок целевых путей не выведено.
- SHA-256 восьми проверяемых файлов игры/кэша до и после --check совпадают. Установка на эту машину не выполнялась.
