# Проверка сборки v0.7.5

Дата: 2026-10-15. Цели: Steam и Tempo Launcher, Windows x64.

- `dotnet publish` в режиме Release, `win-x64`, self-contained, single-file завершён успешно. Версия обоих EXE: **0.7.5.0**.
- Встроенные `translation-patch.json` и `gamedata-tooltips.json` совпадают с исходными ресурсами по SHA-256.
- Патч содержит **17 326** переводов. Относительно v0.7.4 добавлены ровно 27 ключей (26 новых описаний обновления и титул `From the Beginning`), изменён ровно один общий ключ для прибавки к характеристике предметов. Других изменений переводов нет.
- JSON разбирается, дубликатов ключей нет; ключи 26 новых оригиналов соответствуют MD5 английского текста, переменные сохранены. Титул подтверждён одноимённым ключом в официальных локализационных базах других языков.
- `--verify-patch` успешно выполнен для обоих EXE и показывает 17 326 переводов.
- `--check` успешно выполнен для Steam и Tempo без установки; SHA-256 восьми проверенных игровых файлов до и после не изменился.
- Установка патчера и проверка отображения новых строк в запущенной игре в ходе сборки не выполнялись.
