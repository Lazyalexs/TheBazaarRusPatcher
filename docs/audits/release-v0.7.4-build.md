# Проверка сборки v0.7.4

Дата: 2026-10-08. Цели: Steam и Tempo Launcher, Windows x64.

- dotnet publish Release, win-x64, self-contained, single-file завершён успешно.
- Версия сборки и обоих EXE: 0.7.4.0.
- Встроенные translation-patch.json и gamedata-tooltips.json совпадают с исходными ресурсами по SHA-256.
- 17299 переводов, 139 записей словаря. Относительно v0.7.3 изменён только ключ `93094c8a49d38079fff54df097b9ba04`: Concede, «Сходить в экспедицию» → «Сдаться». Остальные переводы и словарь сохранены.
- JSON без дубликатов, соответствие источнику, ручному решению и журналу проверены при исправлении.
- --verify-patch успешно выполнен для обоих именованных EXE; оба выводят 17299 записей.
- --check успешно выполнен для Steam и Tempo, без установки. Общий кэш ru-RU.bytes сообщает ровно одну строку для обновления.
- SHA-256 восьми проверяемых файлов игры/кэша до и после --check совпадают. Установка на эту машину не выполнялась.
