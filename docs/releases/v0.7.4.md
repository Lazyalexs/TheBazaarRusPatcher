# v0.7.4 — исправление кнопки в меню паузы

Небольшое обновление русификатора The Bazaar для Steam и Tempo Launcher.

## Что исправлено

- Последняя красная кнопка в меню паузы теперь называется **«Сдаться»** вместо ошибочного «Сходить в экспедицию». Английский оригинал кнопки — Concede.

Все переводы Season 19 и исправления версии v0.7.3 сохранены. Всего в патче **17 299 записей перевода**.

## Скачать и установить

- `TheBazaarRusPatcher-Steam.exe` — для Steam.
- `TheBazaarRusPatcher-Tempo.exe` — для Tempo Launcher.

Полностью закройте игру и лаунчер, скачайте EXE для своего варианта и запустите патчер. Выберите пункт 1 для установки, затем запустите игру заново. Перед изменением файлов патчер создаёт резервные копии; для отката используйте `--restore`.

Если обновление игры перезаписало перевод, повторно установите русификатор.
