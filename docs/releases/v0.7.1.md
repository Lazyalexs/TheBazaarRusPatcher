# v0.7.1 — уточнение терминологии тегов карточек

Обновление русификатора для The Bazaar 18.3. Патчер доступен для Steam и Tempo Launcher.

## Что изменилось

- Уточнены подписи тегов карточек и согласованы с формулировками в описаниях предметов.
- Тег `Apparel` теперь отображается как «Экипировка».
- Унифицированы упоминания транспорта, технологий, друзей и недвижимости в описаниях и условиях эффектов.
- Сохранены игровые переменные и форматирование; встроенный патч содержит 16 948 строк.
- Сборка проверена автором в игре.

## Скачать и установить

- `TheBazaarRusPatcher-Steam.exe` — для Steam.
- `TheBazaarRusPatcher-Tempo.exe` — для Tempo Launcher.

Закройте игру и лаунчер, скачайте EXE для своего варианта и запустите патчер. Выберите пункт 1 для установки. Перед изменением файлов патчер создаёт резервные копии; для отката используйте `--restore`.
