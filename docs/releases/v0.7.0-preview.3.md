# v0.7.0-preview.3 — ручная вычитка перевода для The Bazaar 18.3

Предварительная версия русификатора для патча игры 18.3.

## Что изменилось

- Завершён ручной проход по всем **16 948 строкам** базы: английский оригинал сопоставлялся с текущим русским переводом.
- В реестре вычитки зафиксировано **7 979 подтверждённых правок**; в этой версии по сравнению с preview.1 изменено 6 556 переводов и добавлено 13 ключей.
- Повторно сверены теги карточек: `Core` отображается как «Ядро», `Apparel` — как «Одежда»; исправлены и другие ошибочные подписи, включая `Aquatic`, `Relic` и `Vehicle`.
- Уточнены сообщения патчера о `maintenance.json`: локальная правка списка языков может быть перезаписана ответом сервера и не гарантирует появления русского языка в меню.

## Что ещё не подтверждено

- **1 216 строк** требуют дополнительного контекста и не считаются окончательно закрытыми.
- Для **435 ключей** английский оригинал пока не найден; для **702 ключей** источники дают конфликтующие варианты. Неизвестные оригиналы не подменялись догадками.
- Полное тестирование в актуальной версии игры не проводилось. Проверка сборки и встроенного патча не заменяет проверку всех экранов в игре.

## Скачать

- `TheBazaarRusPatcher-Steam.exe` — Steam.
- `TheBazaarRusPatcher-Tempo.exe` — Tempo Launcher.

Закройте игру и лаунчер, скачайте файл для своего варианта и запустите патчер. Выберите пункт 1 для установки. Перед установкой патчер создаёт резервные копии; для отката используйте `--restore`.

После обновления игры патч может потребовать повторной установки. Русский язык может отсутствовать в меню, если клиент заменил локальный список языков ответом сервера.
