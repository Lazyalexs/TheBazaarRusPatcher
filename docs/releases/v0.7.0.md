# v0.7.0 — ручная вычитка перевода для The Bazaar 18.3

Русификатор для Steam и Tempo Launcher, подготовленный для патча игры 18.3.

## Что сделано

- Проведён ручной проход по базе из **16 948 строк** с сопоставлением английских оригиналов и русских переводов.
- Зафиксированы **7 979 правок**: уточнены смысл, игровые условия, грамматика и терминология.
- Повторно сверены теги карточек; согласованы подписи, включая «Ядро» и «Одежда».
- Уточнены сообщения патчера о локальном `maintenance.json` и обновлении списка языков с сервера.

## Скачать и установить

- `TheBazaarRusPatcher-Steam.exe` — для Steam.
- `TheBazaarRusPatcher-Tempo.exe` — для Tempo Launcher.

Закройте игру и лаунчер, скачайте EXE для своего варианта и запустите патчер. Выберите пункт 1 для установки. Перед изменением файлов патчер создаёт резервные копии; для отката используйте `--restore`.

После обновления игры может потребоваться повторно запустить патчер. Если пункт «Русский» отсутствует в меню, игра могла заменить локальный список языков ответом сервера.
