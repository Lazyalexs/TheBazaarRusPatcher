## Установка

Закройте игру и лаунчер. Скачайте файл для своей версии:

- `TheBazaarRusPatcher-Steam.exe` — Steam.
- `TheBazaarRusPatcher-Tempo.exe` — Tempo Launcher.

Запустите патчер и выберите пункт 1. Затем запустите игру через лаунчер и, если он доступен, выберите русский язык в настройках.
После обновлений игры может потребоваться повторная установка русификатора.

## Известные ограничения (уточнено 23 сентября)

Пункт «Русский» может отсутствовать после обновления списка языков с сервера. Повторная установка патчера не гарантирует его появления. В переводе остаются неверные названия и грамматические ошибки; исправления следующей версии ещё не входят в эти EXE.
