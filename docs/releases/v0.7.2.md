# v0.7.2 — исправления по результатам проверки карточек

Обновление русификатора The Bazaar для Steam и Tempo Launcher.

## Что изменилось

- Исправлены замеченные в карточках ошибки смысла, грамматики и согласования динамических значений.
- Уточнены названия предметов и формулировки условий для игровых типов «Еда», «Друг», «Щит» и «Дракон».
- Исправлены отдельные описания зарядки, полёта и получения эффектов; унифицирован термин «мультивыстрел».
- Сохранены ключи локализации и подстановочные переменные патча.

## Скачать и установить

- `TheBazaarRusPatcher-Steam.exe` — для Steam.
- `TheBazaarRusPatcher-Tempo.exe` — для Tempo Launcher.

Закройте игру и лаунчер, скачайте EXE для своего варианта и запустите патчер. Выберите пункт 1 для установки. Перед изменением файлов патчер создаёт резервные копии; для отката используйте `--restore`.
